# نصب movim در ویندوز

فایل movim-Setup.exe را اجرا و مراحل نصب را دنبال کنید. گزینه افزودن به PATH را فعال نگه دارید. پس از نصب، یک پنجره جدید PowerShell باز کنید و `nvim` را اجرا کنید. برای باز کردن پروژه، از `nvim "C:\path\to\project"` استفاده کنید.

نصب‌کننده فونت DejaVuSansM Nerd Font Mono را برای کاربر نصب می‌کند. برای نمایش حروف فارسی و آیکن‌ها، این فونت را در بخش Appearance پروفایل Windows Terminal انتخاب و ترمینال را دوباره باز کنید.

Neovim، Node.js، ripgrep، lazygit، افزونه‌ها و ابزارهای زبان داخل بسته هستند. قابلیت‌های Git و به‌روزرسانی افزونه‌ها به Git for Windows نیاز دارند. نصب برای کاربر جاری است و تنظیمات قبلی Neovim را جایگزین نمی‌کند.
