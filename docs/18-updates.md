# به‌روزرسانی movim

movim پس از اجرا در پس‌زمینه جدیدترین **نسخهٔ پایدار منتشرشده در GitHub Releases** را بررسی می‌کند. اگر شمارهٔ نسخهٔ جدیدتر باشد، اعلان شامل لینک صفحهٔ دانلود ظاهر می‌شود؛ هیچ فایلی خودکار نصب یا جایگزین نمی‌شود. بررسی حداکثر روزی یک بار انجام می‌شود و به اتصال اینترنت و `curl` نیاز دارد.

برای بررسی دستی دستور `:MovimCheckUpdate` را اجرا کنید. برای غیرفعال‌کردن بررسی خودکار، پیش از بارگذاری تنظیمات مقدار `vim.g.movim_check_updates = false` را قرار دهید؛ دستور بررسی دستی همچنان کار می‌کند.

در سایت نیز پس از انتشار نسخهٔ جدید، آخرین بسته‌های موجود و در صورت بازدید مجدد اطلاعیهٔ نسخهٔ جدید نمایش داده می‌شود. پس از دریافت بستهٔ مناسب، دستورالعمل نصب همان سیستم‌عامل را دنبال کنید. نسخه‌های پیش‌نمایش به‌عنوان نسخهٔ پایدار پیشنهاد نمی‌شوند.
