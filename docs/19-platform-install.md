# نصب movim روی سیستم‌های مختلف

فایل‌های منتشرشدهٔ هر نسخه از صفحهٔ GitHub Releases یا بخش دریافت سایت در دسترس‌اند. اگر فایل پلتفرم شما در انتشار موجود نیست، ابتدا باید همراه یک نسخهٔ جدید منتشر شود.

## ویندوز x64

فایل `movim-Setup.exe` را دریافت و اجرا کنید. نصب‌کننده Neovim و ابزارهای همراه را به‌صورت جداگانه نصب می‌کند. Git for Windows برای قابلیت‌های گیت و برخی به‌روزرسانی‌ها لازم است. بعد از نصب یک PowerShell جدید باز کنید و `movim` یا `movim "C:\path\to\project"` را اجرا کنید. دستور `nvim` نیز همان لانچر را اجرا می‌کند. گزینهٔ افزودن به PATH باید در نصب فعال باشد.

## مک: Apple Silicon و Intel

فایل مشترک `movim-macOS.zip` را دریافت، کامل استخراج و `Install.command` را اجرا کنید. نصب‌کننده برای تهیهٔ Neovim، Node، ripgrep و ابزارهای دیگر از Homebrew استفاده می‌کند؛ اتصال اینترنت لازم است. پس از نصب در ترمینال `movim` را اجرا کنید. این بسته مستقل از معماری تهیه می‌شود و معماری ابزارها را Homebrew برای همان دستگاه انتخاب می‌کند.

## لینوکس x86_64 و ARM64

ابتدا Neovim نسخهٔ ۰٫۱۱ یا جدیدتر، Git، Node.js/npm، ripgrep و curl را از روش مناسب توزیع خود نصب کنید. برای بعضی افزونه‌ها کامپایلر C و ابزارهای ساخت نیز لازم است. سپس `movim-linux.tar.gz` را دریافت و اجرا کنید:

```sh
tar -xzf movim-linux.tar.gz
cd movim-linux
bash Install.sh
~/.local/bin/movim
```

این نصب تنظیمات را در `${XDG_CONFIG_HOME:-~/.config}/movim` جدا از تنظیمات معمول Neovim قرار می‌دهد و تنظیمات قبلی movim را پیش از جایگزینی پشتیبان می‌گیرد. نصب افزونه‌ها و سرورهای زبان به اینترنت و وابستگی‌های مربوط نیاز دارد. اگر `~/.local/bin` در PATH است، بعداً کافی است `movim` را اجرا کنید.
