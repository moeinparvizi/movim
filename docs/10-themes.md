# فصل ۱۰ — تم و ظاهر

## تم پیش‌فرض: TokyoNight

تم اصلی **tokyonight-night** است (همان تیره آبی-بنفش معروف). چهار واریانت دارد:

- `tokyonight-night` — تیره اصلی (پیش‌فرض)
- `tokyonight-moon` — تیره‌تر با رنگ‌های گرم‌تر
- `tokyonight-storm` — ملایم‌تر از night
- `tokyonight-day` — روشن

## انتخاب تم (persist می‌شود!)

| کلید | کار |
|---|---|
| `<leader>ut` یا `:Themes` | گالری تم با پیش‌نمایش و نصب |

با تایپ نام، تم‌ها را جست‌وجو کنید و با فلش یا `Ctrl+j/k` بین آن‌ها حرکت کنید.
تم‌های نصب‌شده با `✓` مشخص‌اند و هنگام انتخاب، روی ادیتور به‌صورت زنده پیش‌نمایش
می‌شوند. برای موارد دارای علامت `↓`، نمونهٔ تقریبی رنگ‌ها نمایش داده می‌شود؛
`Enter` آن تم را با Git نصب و فعال می‌کند. `Enter` روی تم نصب‌شده آن را فعال
می‌کند و `Esc` بدون ذخیره به تم قبلی برمی‌گردد. نصب به اینترنت و Git نیاز دارد.
برای نصب تم دیگری از GitHub، در گالری `Ctrl+G` را بزنید و نام مخزن را به شکل
`owner/repository` وارد کنید. بعد از نصب، گالری دوباره باز می‌شود تا تم را انتخاب کنید.

انتخاب تأییدشده برای اجرای بعدی ذخیره می‌شود. مسیر فایل تنظیمات بسته به سیستم
و نصب متفاوت است؛ برای دیدن آن از `:echo stdpath('state')` استفاده کنید.

گالری علاوه بر تم‌های نصب‌شده، مواردی مانند Dracula، Nordic، Everforest، VS Code
و تم‌های GitHub را برای نصب نشان می‌دهد.
