# فصل ۱۱ — TODO و بوکمارک

## TODO ها (Task list وب‌استورم)

کلیدواژه‌های شناسایی‌شده در کامنت‌ها:

| کلیدواژه | معنی |
|---|---|
| `TODO:` | کار باقی‌مانده |
| `FIXME:` / `BUG:` / `FIX:` | چیز خراب |
| `HACK:` | راه‌حل موقت |
| `NOTE:` / `INFO:` | یادداشت |
| `PERF:` / `OPTIMIZE:` | بهینه‌سازی |
| `WARN:` / `XXX:` | هشدار |
| `TEST:` | تست |

همه با آیکون و رنگ در gutter هایلایت می‌شوند.

| کلید | کار |
|---|---|
| `<leader>st` | جستجوی fuzzy بین همه TODO های پروژه |
| `<leader>xt` | پنل Trouble: لیست TODO ها (مثل TODO tool window) |
| `]t` / `[t` | TODO بعدی/قبلی در فایل |

## بوکمارک‌های movim

بوکمارک‌ها برای خط‌های فایل ثبت می‌شوند، در کنار خط علامت دارند و بعد از
بستن و بازکردن movim باقی می‌مانند. بعد از `Space`، گروه Bookmarks را ببینید:

| کلید | کار |
|---|---|
| `Space k t` | افزودن یا حذف بوکمارک خط جاری |
| `Space k l` | فهرست قابل‌جست‌وجو با پیش‌نمایش؛ `Enter` برای بازکردن و `Ctrl+D` برای حذف |
| `Space k n` / `Space k p` | رفتن به بوکمارک بعدی / قبلی در فایل‌ها |

در کنار این قابلیت، مارک‌های معمولی Vim و پلاگین marks.nvim همچنان در دسترس‌اند:
`m` همراه یک حرف مارک می‌گذارد، `'` همراه همان حرف به آن می‌رود و `m;`
مارک بعدی را روی خط جاری تغییر می‌دهد. `F11` برای دیباگ رزرو شده است.

## بوکمارک‌های داخلی ویم (خودکار)

| مارک | معنی |
|---|---|
| `` `. `` | آخرین تغییر |
| `` `" `` | جایی که فایل بسته شده بود (خودکار برگردانده می‌شود) |
| `` `^ `` | آخرین محل خروج از insert |
| `` `< `` / `` `> `` | ابتدا/انتهای آخرین انتخاب |
