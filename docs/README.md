# راهنمای کامل فارسی movim

این راهنما، **آموزش کامل فارسی movim** است؛ از اولین اجرای Neovim تا ویرایش، گیت، تست و دیباگ. ۲۰ فصل اصلی و ۵ مرجع کاربردی در کنار این فهرست قرار دارند. قابلیت‌های سرور زبان و دیباگر به ابزارها و تنظیمات پروژهٔ شما بستگی دارند.

> **مسیر پیشنهادی یادگیری:** اگر با Vim تازه شروع کردید، به ترتیبِ شماره‌ها جلو بروید. اگر کاربر قدیمی Vim هستید، مستقیم بروید سراغ فصل‌های ۶ به بعد که امکانات IDE را پوشش می‌دهند.

## پیدا کردن راهنما در سایت

زبان پیش‌فرض سایت فارسی است. دکمهٔ **مستندات** و **راهنمای کامل فارسی** همین فهرست کامل را باز می‌کنند؛ دکمهٔ **EN** برای انتخاب آگاهانهٔ زبان انگلیسی است و انتخاب شما برای دفعات بعد ذخیره می‌شود. در صفحهٔ راهنمای انگلیسی، دکمهٔ **فارسی** شما را به تمام فصل‌های این راهنما برمی‌گرداند.

با `Ctrl+K`، `Cmd+K` یا کلید `/` کادر جست‌وجو را باز کنید. جست‌وجو متن تمام فصل‌ها را بررسی می‌کند و «ی/ي» و «ک/ك» را یکسان می‌بیند. با فلش بالا و پایین بین نتیجه‌ها حرکت کنید، با Enter نتیجه را باز کنید و با Esc کادر را ببندید. در موبایل از دکمهٔ جست‌وجو و **فهرست تمام فصل‌ها** استفاده کنید. در هر فصل، فهرست بخش‌های همان صفحه و لینک فصل قبل و بعد نیز در دسترس است. جدول‌ها در صفحه‌های کوچک جداگانه اسکرول می‌شوند و دستورها دکمهٔ کپی دارند.

اگر تازه نصب کرده‌اید، [نصب برای هر سیستم‌عامل](19-platform-install.md) و سپس [مبانی Vim](02-basics.md) را بخوانید. برای پیدا کردن فوری یک میان‌بر، [چیت‌شیت کامل](14-keymaps-cheatsheet.md) را باز کنید.

فایل‌های ظاهر، اسکریپت‌ها و فهرست جست‌وجوی سایت با شناسهٔ محتوای خود بارگیری می‌شوند تا مرورگر صفحهٔ جدید را با کد قدیمی ترکیب نکند. بعد از انتشار، یک بار صفحه را دوباره باز کنید؛ اگر صفحه‌ای را از قبل باز نگه داشته‌اید، آن را بازخوانی کنید.

## جدول تطبیق WebStorm ↔ این کانفیگ

| امکانات WebStorm | معادل اینجا |
|---|---|
| Ctrl+T (Update Project) | `<leader>gp` انتخاب شاخهٔ ریموت و مرج با autostash |
| Merge Dialog کانفلیکت | Diffview + `co/ct/cb` انتخاب طرف |
| Shift+F6 (Rename) | `<S-F6>` یا `<F2>` یا `<leader>cr` |
| Ctrl+Alt+Click | Alt+Click (رفتن به تعریف) |
| Alt+Click (افزودن کرسر) | Ctrl+Click (افزودن کرسر) |
| Local History | `<leader>hl` |
| Ctrl+Z / Undo History | `<leader>hu` (Undotree) |
| Double Shift | `<leader>ff` (فایل) / `<leader>fg` (متن) |
| Ctrl+Shift+F (Replace in Path) | `<leader>sr` (Spectre) |
| Structure Panel | `<leader>o` (Aerial) |
| TODO Panel | `<leader>xt` |
| Bookmarks | `Space k t` / `Space k l` |
| Compare with Clipboard | `<leader>Dc` / `<leader>Ds` |
| Shelve/Unshelve | `<leader>gS` / `<leader>gs` |
| Run Configurations | `<leader>rr` / `<leader>rd` |
| Debug (F8/F7/F9) | `F5` / `F10` / `F11` |
| Terminal | `Ctrl+/` |
| Git Panel | `<leader>gg` (lazygit) |
| Theme Selector | `<leader>ut` |

> `<leader>` یعنی کلید **Space**. پس `<leader>gp` یعنی: `Space` بعد `g` بعد `p`.
